Smart Calorie Tracker

A full-stack health application built with Django and PostgreSQL. It allows users to log meals via the OpenFoodFacts API, visualize macro data with Chart.js, and track weight goals over time.

Python Django PostgreSQL Chart.js Bootstrap 5
  • ✅ API Integration: Real-time food search using OpenFoodFacts and locale based weather data from Open Weather API.
  • ✅ Data Visualization: Dynamic doughnut and line charts for macros/weight and a water tracker.
  • ✅ Cloud Hosted: Deployed on Render with a production database.
